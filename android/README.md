# SilentVoix Android

Native Android client for SilentVoix. It is planned to recognize sign language from the device camera and/or the ESP32 glove, and to speak the result.

**Status:** scaffold only. There are no activities, screens, Kotlin classes or business logic yet.

## Tech stack

| Area | Choice |
|---|---|
| Language | Kotlin (AGP built-in Kotlin support) |
| UI | Jetpack Compose + Material 3 |
| Build | Gradle Kotlin DSL, version catalog (`gradle/libs.versions.toml`), AGP 9.4.1, Gradle 9.6.0 wrapper |
| Camera (planned) | CameraX |
| Hand tracking / gestures (planned) | MediaPipe Tasks (Hand Landmarker / Gesture Recognizer) |
| Speech output (planned) | Android `TextToSpeech` |
| Backend comms (planned) | REST over HTTPS, WebSocket |
| Glove (planned) | ESP32 sensor stream over WebSocket, using the existing protocol and backend flow (firmware unchanged) |

Only the Compose / Material 3 baseline is declared for now. CameraX, MediaPipe and networking libraries get added when the matching features are built. No models are bundled.

- Application ID / namespace: `com.silentvoix.app`
- minSdk 24, target/compile SDK 37

## Layout

```
android/
├── settings.gradle.kts, build.gradle.kts, gradle.properties
├── gradle/libs.versions.toml, gradle/wrapper/
└── app/
    ├── build.gradle.kts
    └── src/
        ├── main/AndroidManifest.xml
        ├── main/res/                          # app name, theme, launcher icon, backup rules
        ├── main/java/com/silentvoix/app/      # application code (empty)
        ├── test/java/com/silentvoix/app/      # unit tests (empty)
        └── androidTest/java/com/silentvoix/app/  # instrumented tests (empty)
```

Open the `android/` directory (not the repo root) in Android Studio. `local.properties` (the `sdk.dir` setting) is generated by Android Studio and is git-ignored.

## Constraints to keep

- The glove WebSocket contract is `silentvoix.sensor_frame.v1`: 11 values ordered `accel[3] + gyro[3] + flex[5]`. See `docs/transformation.md` §8.
